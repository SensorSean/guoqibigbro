# 国企大表哥

多源 Excel 数据智能归集桌面工具。按「列名 / 同义词」自动匹配字段，按「行标识」对齐行，
将多个分散的 Excel 数据源一键归集、填充到统一的空白目标模板。

> 本工具完全**离线运行**，所有数据仅在本地处理，不上传、不联网。

## ✨ 核心特性

- **智能字段映射**：内置工程/人事类同义词词典 + Levenshtein 编辑距离 + 中文分词 + 多遍归一化，
  自动把数据源字段匹配到目标模板列
- **行标识对齐**：按行标识（如「立项名称」「姓名」「编号」）对齐源与目标行，不依赖行顺序
- **多源归集**：支持同时加载多个数据源，后加载的优先级更高（同 key 同列取最高优先级）
- **空表自动填充**：目标模板无数据行时，自动从所有源收集唯一行标识并创建对应行
- **保留格式写回**：用 openpyxl 写回，保持模板原有样式、合并单元格与列宽
- **直观桌面 UI**：向导式四步操作（数据源 → 字段映射 → 预览确认 → 执行结果），基于 pywebview

## 📦 环境依赖

- Windows 10 / 11（64 位）
- **Microsoft Edge WebView2 Runtime**（界面运行基础；Win11 大多已自带，Win10 缺则运行 `spec/安装WebView2.bat`）
- Python 3.12+（仅从源码运行 / 构建时需要）

## 🚀 快速开始

### 方式一：直接运行（推荐普通用户）
从 [Release](https://github.com/your-name/your-repo/releases) 下载 `国企大表哥_V1.3.1.exe`，
放到任意目录双击运行即可，无需安装 Python。

> ⚠️ 本软件 exe **未签名**，首次双击可能被 Windows SmartScreen 拦截，点击「仍要运行」即可。

### 方式二：从源码运行
```bash
pip install -r requirements.txt
python main.py
```

### 方式三：从源码构建 exe
```bash
pip install -r requirements_build.txt
python spec/build_exe_v4.py
# 产物：dist/国企大表哥_V1.3.1.exe
```

## 📖 使用说明
完整图文手册见 [使用手册.md](使用手册.md)。
典型流程：加载多个数据源 → 设置表头行 → 加载目标模板 → 智能匹配字段 →
设置行标识键 → 执行填表。

## 📁 目录结构
```
国企大表哥/
├── main.py                 # 程序入口（pywebview 窗口 + 后端）
├── core/                  # 核心逻辑
│   ├── excel_reader.py    # Excel 读取 / 表头解析
│   ├── matcher.py         # 字段匹配引擎（同义词 + 编辑距离）
│   ├── rowkey_matcher.py  # 行标识匹配
│   └── filler.py          # 填充 / 格式写回
├── ui/                    # 前端（HTML/CSS/JS）
├── spec/                  # 构建脚本与 WebView2 安装包
├── 同义词词典.json          # 同义词 / 互斥规则（可自定义扩充）
├── 使用手册.md             # 图文使用手册
└── examples/              # 合成示例数据（无真实业务数据）
```
