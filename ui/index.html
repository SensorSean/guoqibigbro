🎯 核心功能
  • 多源 Excel 智能归集（列名匹配 + 行标识匹配）
  • 同义词识别（中文 / 英文 / 简写）
  • 行级匹配支持项目名称 / 合同编号，可手动纠偏
  • 执行超时保护 + 自定义输出路径
  • 自动保留目标模板格式（表头样式、列宽、合并单元格）
📖 使用说明
使用要求：操作系统 Windows 7 SP1 及以上（含 8 / 8.1 / 10 / 11，64 位推荐）
1
加载数据源
在「数据源」页选择多个 .xlsx / .xls / .csv 文件，跨文件、跨 Sheet 自动识别字段名。
2
选择目标模板
选择要填入的空白表格，自动读取表头作为目标字段；.xls 旧格式会自动转存为 .xlsx。
3
智能匹配字段与行
点「智能匹配」按相似度+同义词自动配对字段；「智能匹配行」按项目名/合同编号自动对齐行，低置信度行可手动改配。
4
核对并执行
在字段映射页核对「源→目标」映射与行配对，设置保存路径后点「开始执行」；进度与日志同页展示，完成后可打开结果文件。
💡 小贴士
  • 后选的数据源优先级更高（同名字段冲突时以最新源为准）
  • 同义词字典已内置「姓名/名字」「电话/手机」等常见别名
  • 行级匹配支持「项目名称」与「合同编号」两种行标识键，可切换
  • 执行过程实时显示已用时长，超时会自动中止并提示
  • 结果文件名格式：原模板名_已填充_YYYYMMDD_HHMMSS.xlsx
